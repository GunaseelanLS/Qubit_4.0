KEY ARCHITECTURAL RULE:

        WHAT QUBIT WANTS TO DO
                    │
                    ▼
             CAPABILITY / TOOL
                    │
                    ▼
        HOW IT SHOULD BE DONE
                    │
                    ▼
             PROVIDER / ADAPTER
                    │
                    ▼
        WHERE IT IS EXECUTED
                    │
                    ▼
       Linux / GNOME / KDE / APP
                    │
                    ▼
       WHETHER IT IS ALLOWED
                    │
                    ▼
          PERMISSION ENGINE

        ┌─────────────────────────────────────────────────────┐
        │              FUTURE EXTENSIBILITY                   │
        │                                                     │
        │  New Capability → Register Tool                     │
        │  New Desktop    → Add Desktop Provider              │
        │  New System API → Add System Provider               │
        │  New Application→ Add Application Adapter           │
        │  New Community Feature → Add Plugin                 │
        │                                                     │
        │  Core Qubit logic does NOT need to be rewritten.    │
        └─────────────────────────────────────────────────────┘
