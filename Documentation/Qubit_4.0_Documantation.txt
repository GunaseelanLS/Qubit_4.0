# Architecture of Qubit 4.0

Qubit_4.0/
├── agent/
│   └── tool_registry.py
│
├── capabilities/
│   ├── applications.py
│   ├── system.py
│   └── windows.py
│
├── computer/          # future generic computer control
├── perception/        # future screen/UI perception
├── platforms/         # future platform-specific adapters
├── memory/            # future memory
├── security/          # future permissions/safety
├── voice/             # future voice abstraction
│
├── window_manager/    # existing KDE/GNOME implementation
│
├── gemini_live.py     # Gemini Live communication
├── main.py            # application entry point
├── config.json
└── Documentation/


agent/ → future agent intelligence; currently only Tool Registry.
capabilities/ → what Qubit can do.
window_manager/ → how window operations currently work on KDE/GNOME.
computer/ → future generic mouse, keyboard, screen, etc.
perception/ → future understanding of the screen/UI.
platforms/ → future OS/platform-specific implementations.
memory/ → future persistent/contextual memory.
security/ → future permissions and safety.
voice/ → future voice abstraction.
gemini_live.py → Gemini Live connection and streaming.
main.py → startup and system wiring.

#Perception:

    Combines active window metadata with OCR results into a structured ScreenPerception object. It extracts screen text,
detected filenames/tabs, and formats the information as context for Gemini alongside the captured image.
